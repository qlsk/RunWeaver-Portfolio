# 튜토리얼 흐름 — 설계 및 시안 수정 요청

> 상태: **설계 (미구현)** · 상세도 **Level 1** · 기준 브랜치 `feature/growth` · 작성일 2026-10-12
> 팀원이 제작한 튜토리얼 UI 시안(10장)을 내용·구조 관점에서 검토한 결과이다. 아트 컨셉은 범위 밖이다.
> 코드는 확인하지 않았다. 구현 대상 클래스는 구현 설계 단계에서 정한다.

## 1. 확정 사항

| # | 쟁점 | 결정 |
|---|---|---|
| T1 | 원소 반응 체험 | **필수 흐름에 포함.** 04에서 두 번째 원소 룬을 장착시키고, 06 전투에서 첫 반응을 보여 준다 |
| T2 | 튜토리얼 임무 실패 | **실패 없음.** 타이머는 표시·진행하되 0이 돼도 실패 처리하지 않고, 체력은 하한을 고정한다. 1층에서만 적용한다 |

## 2. 단계 구조

번호가 있는 필수 단계와 번호가 없는 상황 안내를 분리한다.

**필수 단계 (번호 `NN / 10`, 강제)**

1. 균열 착지 — WASD 이동
2. 시작 석상 — F 상호작용
3. 주력 원소 — 원소 선택
4. 룬 워드 장착 — 원소 룬 2개 장착 (룬석 소모와 해제 시 미환급을 명시)
5. 임무 개시 — F로 임무 표식 상호작용
6. 임무 목표 — 타이머·목표 UI 스포트라이트 (시간 정지 또는 미시작)
7. 사격 — 정령 처치로 완료 (06 전투에서 첫 반응 발생)
8. 대시 — 안전한 시점에 Space 1회로 완료 (피격 대기 없음)
9. 임무 완료 — 보상 선택
10. 다음 층으로 — 포탈 진입

**상황 안내 (번호 없음, 새 기록 카드)**: 원소 각인, 탄창 소진, 룬석 획득, 피격, 남은 시간 10초, 체력 위험, 원소 반응 첫 발생 등. 같은 카드 시스템으로 통일한다.

## 3. 튜토리얼 규칙

- **룬 선택 범위**: 사용 가능한 원소 룬 워드 2개만 열고 나머지는 `???` 잠금으로 표시한다. 추천 조합 1개(예: 불+물=증기)를 정해 두고, 불리한 조합이 나오지 않게 한다.
- **임무 실패 없음**: 타이머가 0이 되면 실패 대신 "협회가 시간을 연장했다" 연출 후 정령을 추가 스폰한다. 체력은 일정 비율 이하로 내려가지 않게 고정한다.
- **건너뛰기**: 일시정지 메뉴의 "튜토리얼 건너뛰기"로 이동하고, 건너뛰면 기본 원소(불)와 기본 룬 워드를 자동 지급한다. 길게 누르기 힌트는 상시 노출하지 않는다.
- **입력**: 확정은 F로 통일한다. Space는 대시 전용이다. 룬북(Tab)은 04 이전에는 잠그고 HUD 힌트도 숨긴다.
- **기록 위치**: 룬북은 장착용, 협회 지침서(Esc 메뉴)는 도감용으로 분리한다. 원소 반응 기록은 한 곳에서만 보이게 한다.
- **카드 배치**: 기본 앵커를 좌상단으로 고정하고, 가리킬 때만 화살표로 연결한다. 한 번에 주 안내는 하나만 두고 "지난 단계" 카드는 몇 초 뒤 사라지게 한다.

## 4. 시안 수정 요청 목록

**용어·문구**
- "정화"가 4가지 뜻으로 쓰인다(상태이상 제거 스킬, 정화 파동, 층 정화 완료, 최심부 정화계). 하나는 다른 단어로 바꾼다.
- 적/정령, 지침/지침서/기록/튜토리얼 호칭을 각각 하나로 통일한다.
- 말투를 하나로 통일한다(카드 "~하라", HUD "~하세요", 안내 "~합니다").
- 월드 마커 "Descend"를 한글로 바꾼다.
- 03의 "처음 고르는 원소는 대가가 없다"를 삭제하거나 의미를 명확히 한다.
- 스펙 시트 A의 02 문구를 실제 화면과 맞춘다.

**내용·구조**
- 04에서 룬석 한 줄 설명을 먼저 제공하고, 주력 원소가 첫 슬롯을 차지하는지 명시한다. 슬롯 수와 "원소 룬 최대 2개" 설명을 일치시킨다.
- 04 체크리스트의 "해제 안내"는 필수 행동이 아님을 표시한다.
- 긴박 카드("남은 시간 10초", "체력 위험")는 1줄·아이콘 중심으로 줄인다.
- 지침서 "기록 N/31"의 카운트 기준(항목 단위)을 정한다.

**레이아웃**
- 04의 안내 카드가 "확인" 버튼 일부를 가리지 않게 한다.
- 02의 안내 카드가 "착지한 균열" 원과 겹치지 않게 한다.
- 전투 중 카드가 적 출현 영역을 가리지 않게 위치를 조정한다.
- 02 화면의 월드 프롬프트, 카드, 마커 중복을 줄인다.
- 스포트라이트(시트 C)를 룬북·보상 선택 화면에서 쓸지 정하고 시안에 반영한다.
